---
name: feedback_dont_blame_logs
description: Never claim user's logs are cut off or missing — accept them as complete and diagnose from what's there
type: feedback
---

When the user provides logs and says "these are all of them," accept that at face value. Do not repeatedly say logs are missing, cut off, or incomplete. Diagnose from what's actually provided. The user got very frustrated when I kept deflecting blame onto "missing logs" instead of analysing what was there.
